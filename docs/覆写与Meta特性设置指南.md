# 覆写设置 & Meta 特性设置 指南

> 适用本仓库（ClashMetaForAndroid / MetaCubeX 分支）。设置页入口：
> **设置 → 覆写**、**设置 → Meta 特性**。

---

## 0. 先搞懂"覆写"是什么

订阅来的配置文件你没法直接改（一更新就还原），"覆写"就是在**每次加载配置时**
把你的设置盖上去，相当于一层永久补丁，保存在核心目录的 `override.json` 里。

两个页面（覆写、Meta 特性）编辑的是**同一份覆写文件**，只是分组展示不同。

通用规则（所有"三态"选项都一样）：

| 选项值 | 含义 |
| --- | --- |
| **不修改** | 跟随订阅配置里怎么写就怎么用（默认） |
| **启用 / 禁用**（或其他具体值） | 强制盖成这个值，无视订阅 |

⚠️ 两个注意点：

1. 任一页面点"重置覆写设置"，清空的是整份 `override.json`——**两个页面的设置会一起被清掉**。
2. 订阅里即使写了 `external-controller`（外部控制 API），App 加载时会**强制剥离**；
   想用面板（yacd / metacubexd 等）只能在这里自己填"外部控制器"。

另外，主页快速切换的"直连/全局/规则"模式是**会话级**的（重启核心就还原），
覆写里的"模式"才是持久的。

## 1. 覆写设置

### 1.1 通用

| 设置 | 说明 | 建议 |
| --- | --- | --- |
| HTTP 端口 / Socks 端口 | 本地 HTTP / SOCKS5 代理监听端口。留空 = 禁用该监听 | 一般不用动；局域网设备想连的话配"复合端口"最省事 |
| Redirect 端口 / TProxy 端口 | Linux 透明代理端口，Android 上基本用不到 | 不动 |
| 复合端口 (mixed-port) | 同一端口同时支持 HTTP + SOCKS5 | 想共享代理给别的设备时填一个（如 7890） |
| 认证 | 给本地代理加用户名密码，格式 `用户名:密码`，多个就多行 | 一般不开 |
| 允许来自局域网的连接 | 关闭时只有本机能连代理；开启后同一 Wi-Fi 的设备可以把手机当代理服务器 | 需要共享时开启，同时安全性下降，建议配合"认证" |
| IPv6 | 代理是否处理 IPv6 流量（连接层） | 手机网络 IPv6 不稳就关 |
| 监听地址 | 代理监听在哪个地址，`*` = 所有网卡 | 配合"允许局域网"用 `*` |
| 外部控制器 | REST API 地址（如 `127.0.0.1:9090`），给 Web 面板连 | 想用面板就填；同时务必设"密钥" |
| 外部控制器 TLS | HTTPS 版外部控制器证书路径 | 一般不用 |
| 允许源 (allow-origins) | 面板的 CORS 白名单，`*` = 任意页面可连 | 本机使用可 `*` |
| 允许私有网络 | 允许来自私有地址的面板请求 | 本机使用可启用 |
| 密钥 | 外部控制器的 Bearer Token | 开外部控制器就必填，防止局域网内别人控制你的代理 |
| 模式 | 直连 / 全局 / 规则（持久生效） | 日常用"规则" |
| 日志级别 | info / warning / error / debug / silent | 排障时临时开 debug，平时 info 或 silent |
| Hosts | 自定义域名 → IP 映射 | 有特殊需求才用 |

### 1.2 DNS

| 设置 | 说明 | 建议 |
| --- | --- | --- |
| 策略 | 三态：**不修改**（用订阅的 DNS；订阅没配则 App 自动注入内置 DNS）/ **强制启用**（强制 `dns.enable=true`，服务器列表仍按订阅）/ **使用内置**（整体替换成 App 内置 DNS：Fake-IP + 默认服务器 + 系统DNS） | 订阅 DNS 没问题时选"不修改"；域名解析抽风时选"使用内置"最省心 |
| H3 优先 | DNS over HTTPS/3（QUIC）优先，更快但部分服务器不支持 | 不动 |
| 监听 | DNS 服务监听地址（如 `0.0.0.0:1053`） | 不动 |
| 追加系统 DNS | 在服务器列表末尾追加 `system://`（手机系统 DNS）。开启后国内域名兜底走系统解析，银行/政务类 App 不容易出问题 | 建议启用 |
| IPv6 | DNS 是否返回 AAAA 记录 | IPv6 环境不稳就禁用 |
| 使用 Hosts | 解析时应用上面的 Hosts 表 | 跟随需求 |
| 增强模式 | **Fake-IP**（返回假 IP，性能最好，是 TUN 模式标配）/ **映射**（redir-host，真实解析） | 保持 Fake-IP |
| Name Server | 主 DNS 服务器列表 | 一般不修改 |
| Fallback Name Server | 国外解析兜底列表 | 一般不修改 |
| Default Name Server | 用来解析 DoH 服务器自身域名的引导 DNS | 一般不修改 |
| FakeIP 过滤器 / 过滤器模式 | 不走 Fake-IP 的域名黑/白名单 | 一般不动；某些 App 异常再加 |
| GeoIP Fallback / 区域代码 | Fallback 结果按 GeoIP 判断（非 CN 才采用），区域默认 CN | 不动 |
| 域名 Fallback / IPCIDR Fallback | 指定域名/IP 段强制走 Fallback | 不动 |
| Name Server 策略 | 按域名指定 DNS 服务器（如 `+.cn: 系统`） | 有分流解析需求时用 |

## 2. Meta 特性设置

### 2.1 Age 密钥

给**支持 age 加密的订阅**用的密钥工具（普通订阅用不到，可无视）：

- **X25519** / **混合**：两种 age 算法的密钥对生成器，点进去可以"生成"密钥对、
  从私钥推导公钥、复制。公钥交给订阅提供方拼进链接，私钥自己留着解密。
- 私钥格式以 `AGE-SECRET-KEY-` 开头，填错会有红字提示。

### 2.2 设置

| 设置 | 说明 | 建议 |
| --- | --- | --- |
| 统一延迟 | 测速时先做一次握手再计时（相当于第二次的 RTT），去掉 TLS 握手开销，**测出来的延迟更真实、两次测量更稳定** | 建议启用 |
| Geodata 模式 | GeoIP 数据读取格式：启用 = 用 `geoip.dat`；禁用 = 用默认 `metadb` | 保持默认（禁用），除非你的规则包依赖 dat 格式 |
| TCP 并发 | 域名解析出多个 IP 时同时发起连接，谁先成功用谁 | 建议启用，能明显降低连接失败率 |
| 查找进程模式 | 规则里 `PROCESS-NAME` 等进程规则的进程查找方式：**关闭**（不查，省电，进程规则失效）/ **严格**（默认，按需查找）/ **总是**（每条连接都查） | 默认"严格"；完全不用进程分流可"关闭" |

### 2.3 嗅探设置

**嗅探器干什么用**：有些 App 直接连 IP（不带域名），域名规则就匹配不上。
嗅探器从流量里读出真实域名（TLS SNI / HTTP Host / QUIC），让分流重新按域名走。

| 设置 | 说明 | 建议 |
| --- | --- | --- |
| 策略 | 启用/禁用嗅探器总开关 | 订阅没配就"启用" |
| HTTP/TLS/QUIC 端口 | 各协议嗅探哪些端口的流量 | 默认即可 |
| 各协议"覆盖目标地址" | 把连接的目标改写成嗅探到的域名（不改则只用于规则匹配） | 默认即可 |
| 强制 DNS 映射 | 对 Fake-IP 结果的连接也做嗅探核对 | 默认（启用） |
| 解析纯 IP 连接 | 对纯 IP 流量也嗅探 | 默认 |
| 覆盖目标地址 | 上面三个的总开关版本 | 默认 |
| 强制解析域名 | 命中这些域名的连接强制嗅探 | 留空 |
| 跳过域名 / 跳过源 IP / 跳过目标 IP | 排除列表，避免误伤 | 留空，除非某 App 被嗅探弄出问题 |

### 2.4 Geo 文件

手动导入地理数据库，替代在线下载（无外网/下载失败时有用）：

- **导入 GeoIP**（存为 `geoip.metadb` 等）：IP 归属地规则用
- **导入 GeoSite**（`geosite.dat`）：域名分类规则用（如 GEOSITE,cn）
- **导入 Country**（`country.mmdb`）：国家代码库
- **导入 ASN**（`ASN.dat`）：运营商/自治域规则用

要求文件扩展名为 `.metadb / .db / .dat / .mmdb`，从手机存储选择后自动拷到核心目录，
重启核心生效。

## 3. 顺带说明：网络设置里的"访问控制"

（本次已改为以下默认值）

- **访问控制模式**默认 = **不允许已选择的应用**（黑名单模式）：
  列表里的 App **直连**，其余 App 全部走代理。
- 默认预置的黑名单是国内常用且**不适合走代理**的 App（微信、抖音、企业微信、
  银联、各银行/券商、交管 12123、个税、B 站、炉石传说、京东、什么值得买等 30 个包名）。
- 之后在 **网络 → 访问控制应用包列表** 里自行增删即可，改完即时生效（仅 VPN/TUN 模式下
  由 VpnService 强制；代理模式无按应用控制能力）。
